# Ezra — M6_fable5 book strategy (literary_marker_aware_v2)

- **Selected strategy:** two-mission chunking: temple restoration under Zerubbabel (1-6) and
  Ezra's reform mission (7-10), one unit per document/episode, with the returnee register (2) and
  the foreign-wives roster (10:18-44) treated as list units.
- **Literature type / mixed genre:** post-exilic narrative built around embedded imperial
  documents (Cyrus edict 1:2-4; correspondence 4:8-22; Tattenai file 5:6-17; Darius decree 6:3-12;
  Artaxerxes rescript 7:12-26); registers (2; 8:1-14; 10:18-44); penitential prayer (9:6-15).
  **Language shift:** 4:8-6:18 and 7:12-26 are Aramaic — a hard discourse boundary signal the
  substrate does not expose (noted for the gap register).
- **Substrate markers considered:** paragraph `p`, list markers `li1` (ch 2; ch 10 roster),
  `pi1`/`b` in the document chapters (indentation of quoted letters — used as embedded-document
  evidence); footnotes evidence-only.
- **Strong's/Hebrew metadata:** evidence-only (Aramaic sections carry Hebrew-style tags);
  `strong_or_hebrew_tags_used: false`.
- **Expected low-confidence regions:** ch 4 (three reigns of opposition compressed; 4:6-23 is a
  chronological parenthesis — classic seam debate); registers (list trigger); 10:18-44 roster.
- **Chapter-only fallback:** not used.
- **Frontier/atlas expectations:** escalation rows for the ch 4 parenthesis, the registers, and
  the Hebrew/Aramaic boundaries.
- **Independent boundary rationale:** boundaries follow document frames and mission episodes
  anchored to substrate paragraph/list/indentation evidence; no template span or other model
  folder used.
