# Lam — M6_fable5 book strategy (literary_marker_aware_v2)

- **Selected strategy:** five poems, five chunks. Poems 1, 2, 4 are 22-verse alphabetic acrostics
  (b break after every verse in the substrate); poem 3 is a 66-verse triple acrostic (b every
  third verse); poem 5 is a 22-verse non-acrostic communal prayer. The acrostic form makes each
  poem indivisible as a literary unit; subdividing poem 3 by letter-triplet was considered and
  rejected because the acrostic is one sustained lament arc.
- **Literature type / mixed genre:** acrostic lament poetry (qinah meter); poem 3 individual
  lament voice; poem 5 communal petition.
- **Substrate markers considered:** `b` break density confirms verse-per-letter structure
  (b@1-21 in c1/c2/c4; every-third-verse pattern visible in c3); `q1/q2` throughout; footnotes
  evidence-only.
- **Strong's/Hebrew metadata:** evidence-only; acrostic letter sequence (including the ayin/pe
  order variation between poems) noted as structure evidence; `strong_or_hebrew_tags_used: false`.
- **Expected low-confidence regions:** none for boundaries (poem edges are certain); every chunk
  is chapter-coincident and marker-rich so the protocol caps all five at medium_low — a clear case
  where the cap misprices genuinely certain boundaries (logged for harness_recommendations).
- **Chapter-only fallback:** not applicable — poem=chapter identity, not fallback.
- **Frontier/atlas expectations:** five capped rows; the real review question is stanza-level
  sub-chunking policy for acrostics, queued as an atlas consideration.
- **Independent boundary rationale:** acrostic frames define the units; no template span or other
  model folder used.
