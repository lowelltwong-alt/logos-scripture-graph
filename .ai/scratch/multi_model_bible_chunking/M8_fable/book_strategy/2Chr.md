## 1. Genre and device matrix (register-dominant royal narrative)

2Chr is royal-court narrative prose end to end: no genealogical front matter
(that was 1Chr 1-9), no psalm medley chapter. The only poetry markers in WEB are
the doxology refrain at 5:13 and 7:3 ("for he is good; for his loving kindness
endures forever" — the Chronicler's liturgical signature; tier-4 as markup,
tier-1 as refrain when quoted from the text).

Boundary-driving devices (tier-1, in rough order of frequency):
- REGNAL ACCESSION formulas: age-formula type (בֶּן N שָׁנָה מָלַךְ X — 25:1,
  29:1, 33:1 verified specimens) and succession type (וַיִּמְלֹךְ X בְּנוֹ
  תַּחְתָּיו — 17:1) and synchronism type (בִּשְׁנַת... וַיִּמְלֹךְ — 13:1).
- REGNAL DEATH-AND-SUCCESSION formulas: וַיִּשְׁכַּב X עִם אֲבֹתָיו (21:1
  verified; 14:1/MT 13:23 the offset-zone specimen).
- SOURCE-CITATION formulas closing reigns: וְיֶתֶר דִּבְרֵי X (13:22 verified;
  expect at 9:29, 12:15, 16:11, 20:34, 24:27, 25:26, 26:22, 27:7, 28:26, 32:32,
  33:18, 35:26-27, 36:8) — list/register-formula class, strong unit-closers.
- TIME-FRAME transitions: וַיְהִי מִקֵּץ (8:1), אַחֲרֵי הַדְּבָרִים הָאֵלֶּה
  (expect 32:1), וּכְכַלּוֹת כָּל זֹאת (31:1) — verified specimens.
- SCENE/PARTICIPANT changes: וַיֵּלֶךְ רְחַבְעָם שְׁכֶמָה (10:1), return notice
  וַיָּשָׁב... בְּשָׁלוֹם (19:1).
- ASSEMBLY-SUMMONS frames: אָז יַקְהֵיל שְׁלֹמֹה (5:2); קהל-family openings
  recur (15:9-10, 20:4-5, 23:2-3, 29:4, 30:2-3, 34:29-30).
- COMPLETION formulas: וַתִּשְׁלַם כָּל הַמְּלָאכָה (5:1, carries the SAMEKH+PE
  double mark); שלם-completion notices at 8:16, 29:35b.
- SPEECH/ORACLE/PRAYER frames: messenger + prophet-notice frames (Shemaiah 11:2-4,
  12:5-8; Azariah 15:1-7; Hanani 16:7-9; Micaiah ch 18; Jahaziel 20:14-17; Zechariah
  24:20-22; Oded 28:9-11; Huldah 34:22-28); royal speeches (Abijah 13:4-12,
  Hezekiah 29:5-11, 30:6-9 letter, 32:7-8); prayers (Solomon 6:14-42, Asa 14:11,
  Jehoshaphat 20:5-12, Hezekiah 30:18b-19, Manasseh notice 33:12-13).
- LETTER insets: Elijah's letter 21:12-15; Hezekiah's couriers 30:6-9;
  Sennacherib's letters notice 32:17.

INSET RULE (carried from 1Chr, adapted): prayers, speeches, oracles, and letters
stay INSIDE their host narrative units unless a tier-1 frame isolates them (both
an opening frame and a resumption after). When a writer argues an inset as its
own row, the frame verses must be quoted in the rationale and the host unit's
integrity addressed in rejected_alternative.

## 3. Dual-cite zones (crosswalk content-verified Phase 0, both edges)

- WEB 2:1-18 = MT 1:18-2:17 (whole temple-preparation chapter).
- WEB 14:1-15 = MT 13:23-14:14 (Abijah death + Asa opening).
Every original-language ref inside these zones states BOTH numbers. Sub-verse
claims near zone seams need explicit in-row establishment (1Chr 27:30/31
clause-divergence precedent) or insufficient_evidence.

## 4. Synoptic discipline (binding)

Kings/Isaiah/Jeremiah/Ezra parallels (Solomon chs 1-9 = 1Kgs 3-10; ch 10 onward
tracks 1Kgs 12-2Kgs 25 selectively; ch 32 = 2Kgs 18-20/Isa 36-39; 36:22-23 =
Ezra 1:1-3) are CROSS-BOOK metadata / typed relations only — never boundary
evidence; 2Chr seams are decided from 2Chr's text. IN-BOOK parallels ARE
arguable literary evidence: 1:14-17 ≈ 9:25-28 (wealth notice inclusio around the
whole Solomon block); the 5:13 ≈ 7:3 refrain pair bracketing the dedication
theophany; recurring reform/apostasy cycle shapes.
