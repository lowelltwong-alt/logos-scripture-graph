# Book Strategy — 1Thess (M2_claude_sonnet5)

- **strategy_id:** literary_marker_aware_v2 | **book:** 1Thess | **pilot_book:** false

## Selected strategy
Epistolary-argument chunking following 1Thess's greeting/thanksgiving/argument/exhortation/closing
structure, combining or subdividing chapters where the argument itself does so.

## Literature type / mixed genre
epistle_greeting, epistle_argument, and epistle_closing.

## Substrate markers considered
Poetry/liturgy flags checked per chapter; noted transparently where a passage is widely recognized
in scholarship as hymnic (Phil.2:6-11, Col.1:15-20) despite not being substrate-flagged as poetic
in this WEB edition, rather than silently assuming or silently omitting that recognized status.

## Strong's metadata — evidence only
Not used to resolve any interpretive question.

## Chapter-only fallback
Used where the argument coincides with chapter boundaries; not used where it spans or subdivides
them (e.g., Col.1.24-2.5, 1Thess ch.4 split at 4:12/4:13).

## Expected low-confidence / doctrinally sensitive regions
See per-chunk rationale; concentrated at Christ-hymn passages, household codes, and (for the
Thessalonian letters) the eschatological passages.
