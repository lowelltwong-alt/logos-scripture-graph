# Book Strategy — Lamentations (M2_claude_sonnet5)

- **strategy_id:** literary_marker_aware_v2 | **book:** Lam | **pilot_book:** false

## Selected strategy
One chunk per chapter, which genuinely matches this book's own structure — each of the five
chapters is an independent acrostic (or near-acrostic) poem lamenting Jerusalem's fall. This is
not a silent chapter-only default; it reflects the well-documented compositional fact that each
chapter is bounded by the Hebrew alphabet's 22 letters (chapters 1, 2, 4 use one verse per
letter; chapter 3 uses three verses per letter, hence 66 verses; chapter 5 matches the 22-verse
count without being a strict acrostic).

## Literature type / mixed genre
psalm_lament throughout.

structure.
