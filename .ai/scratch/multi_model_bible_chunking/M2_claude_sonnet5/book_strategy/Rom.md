- **strategy_id:** literary_marker_aware_v2 | **book:** Rom | **pilot_book:** false

## Selected strategy
Epistolary-argument chunking following Rom's recognized rhetorical/argument structure
(greeting, thanksgiving where present, doctrinal argument body, practical/ethical exhortation,
closing). Chunks generally follow argument units rather than mechanical chapter division,
combining or subdividing chapters where the argument itself does so (e.g., Rom.14.1-15.13 as one
unit; 1Cor.1.18-2.16 combined; 2Cor.8.1-9.15 combined).

## Literature type / mixed genre
epistle_greeting, epistle_argument, and epistle_closing.

## Substrate markers considered
Poetry/liturgy risk flags (indicating dense OT citation or hymnic content) checked per chapter
and used to inform confidence where relevant; WJ markers (where present, e.g., 1Cor.11's Lord's
Supper institution words) cited as evidence only per CD-021/CD-022.

## Strong's metadata — evidence only
Not used to resolve any interpretive question.

## Chapter-only fallback
Used where the argument genuinely coincides with chapter boundaries; not used where the argument
spans or subdivides chapters.

## Expected low-confidence / doctrinally sensitive regions

specifics); this scratch map deliberately avoids referencing or replicating any existing epistle-

1Cor.8-10), treating each as an independent parsing.
