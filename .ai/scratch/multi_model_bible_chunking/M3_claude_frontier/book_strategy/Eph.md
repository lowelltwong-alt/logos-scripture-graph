# Ephesians — M3 frontier chunking strategy

**Strategy id:** `literary_marker_aware_v2` (frontier pass). **Literature type:** epistle
(`genre_epistles`): a two-part letter — doctrine (1–3) then paraenesis (4–6) — with long liturgical
Greek sentences.

## Markers / evidence
`has_poetry_or_liturgy_marker` at ch4 (OT citation); otherwise prose. `has_strong_g` — Strong's
**Greek evidence only**. `has_crossref`/`x` — evidence only.

## Boundary handling (independent rationale)
Chunked by **rhetorical unit**: greeting (1:1–2); the **eulogy** (1:3–14, one long Greek sentence on
election in Christ); thanksgiving-prayer (1:15–23); grace through faith (2:1–10); one new humanity
(2:11–22); the mystery (3:1–13); prayer/doxology (3:14–21); unity and gifts (4:1–16); the new walk
(4:17–5:20, arc); the household code (5:21–6:9); the armour of God and closing (6:10–24).

## Strong's / WJ handling (evidence only)
Strong's Greek is **evidence only**; never used to set a boundary or decide doctrine. `wj` n/a.

## Low-confidence & frontier escalation triggers
The eulogy's **election/predestination** (1:3–14), **grace through faith** (2:8–9), and the
**marriage/Christ-and-church** household code (5:21–33) flagged — surfaced, not decided.

## Why this is not silent chapter-only
Boundaries follow the Greek sentence/rhetorical units; the eulogy and the household code are isolated
as their own units, several crossing chapters — this is not a chapter map.
