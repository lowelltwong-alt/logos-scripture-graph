# Bible Raw Sources

## English WEB Classic

Drop the eBible WEB Classic USFM archive here:

```text
eng-web/usfm/eng-web_usfm.zip
```

## Hebrew Bible

Use WLC/Open Scriptures/MACULA source packages only with license manifests.

```text
hebrew-wlc/raw/
```

## Greek New Testament

Use SBLGNT, Robinson-Pierpont, or other permitted sources with manifests.

```text
greek-nt/sblgnt/raw/
greek-nt/robinson-pierpont/raw/
```

## Septuagint

Use public-domain or licensed LXX sources with manifests.

```text
lxx-swete/raw/
```
