# Raw Source Vault

This directory is the only place to drop downloaded Bible/source files.

## Rules

- Raw files are immutable.
- Do not hand edit raw files.
- Do not put processed files here.
- Do not mix copyrighted and public-domain files without clear license metadata.
- Every raw source must have a source manifest and checksum before ingestion.

## Expected source families

```text
bible/eng-web/usfm/eng-web_usfm.zip
bible/hebrew-wlc/raw/
bible/greek-nt/sblgnt/raw/
bible/greek-nt/robinson-pierpont/raw/
bible/lxx-swete/raw/
crossrefs/tsk/raw/
lexicon/macula-hebrew/raw/
lexicon/macula-greek/raw/
```
