# Codex Review Packet

Use Cursor Agent mode only after the exact target and allowed paths are explicit.

Prepare a review handoff with:

- branch and base commit;
- exact target candidate id and span;
- mode used and slash commands used;
- files read and files changed;
- commands run and timeout ceilings used;
- validation results;
- stop conditions checked;
- non-authorizations confirmed;
- temp/build paths created;
- exact questions for Codex review.

Confirm no embeddings, vector indexes, graph edges, boundary imports, source/manuscript rows,
backend choices, retrieval-profile promotions, child spans, route/evaluator changes, eval-gold
changes, or chunk output changes were performed.
