# T354 WJ Marker Inventory Harness

## Purpose

T354 creates a deterministic, evidence-only inventory for observed words-of-Jesus / red-letter
marker token runs in the canonical `eng-web` word tokens.

The current source does expose WJ evidence. Canonical word tokens preserve `wj` in
`nesting_context`, and the generated inventory records:

- 38,094 WJ word tokens;
- 675 WJ token runs;
- WJ evidence in `Matt`, `Mark`, `Luke`, `John`, `Acts`, `1Cor`, `2Cor`, `1Tim`, and `Rev`;
- WJ evidence outside the four Gospels, including Acts, epistle quotations, and Revelation.

## Generated Surface

Machine-readable inventory:

```text
.ai/control/wj_marker_inventory.yaml
```

Generated by:

```text
python scripts/build_wj_marker_inventory.py --write
```

Validated by:

```text
python scripts/validate_wj_marker_inventory.py
```

## Authority

The inventory records source observations only.

It does not authorize:

- Jesus speaker attribution;
- speaker boundaries;
- discourse boundaries;
- graph edges;
- chunk boundaries;
- retrieval truth;
- reviewed gold;
- output changes.

This matters especially for passages where WJ evidence is real but the interpretation remains
review-sensitive, such as John 3, John 13-17, Acts speech reports, epistle dominical quotations,
and Revelation voice shifts.

## Downstream Rule

Any future output-changing use of WJ/red-letter evidence requires:

- owner review;
- exact scoped target;
- reviewed speaker/discourse evidence or reviewed gold;
- decision-register update;
- executable tests;
- non-target identity proof;
- later implementation authorization.

## No Output Change

T354 does not modify raw data, canonical data, generated chunks, evaluators, route behavior, graph
edges, embeddings, retrieval indexes, or reviewed gold.
