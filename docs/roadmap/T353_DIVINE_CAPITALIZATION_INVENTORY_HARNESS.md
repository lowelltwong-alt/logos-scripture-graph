# T353 Divine Capitalization Inventory Harness

## Purpose

T353 creates a deterministic, evidence-only inventory for observed English capitalization variants
that could otherwise smuggle theology into future chunking, retrieval, or graph work. Single-token
variants are summarized from canonical word tokens; phrase variants are observed from canonical
translation witness text because some phrase surfaces can be present in witness text without a
corresponding standalone word-token surface.

The inventory covers watch terms and phrases such as:

- `God/god/GOD`
- `LORD/Lord/lord`
- `Spirit/spirit`
- `Father/father`
- `Son/son`
- `Word/word`
- `Christ/christ`
- `Messiah/messiah`
- `Holy Spirit`
- `Son of God`
- `Son of Man`
- `Word of God`
- `Lamb of God`
- `Alpha and the Omega`
- divine-pronoun casing such as `He/he`, `Him/him`, `His/his`, and `Himself/himself`

## Generated Surface

Machine-readable inventory:

```text
.ai/control/divine_capitalization_inventory.yaml
```

Generated by:

```text
python scripts/build_divine_capitalization_inventory.py --write
```

Validated by:

```text
python scripts/validate_divine_capitalization_inventory.py
```

## Authority

The inventory records source observations only.

It does not authorize:

- divine identity;
- Trinitarian relation;
- Christology;
- pneumatology;
- speaker attribution;
- lexical truth;
- graph edges;
- chunk boundaries;
- retrieval truth;
- output changes.

Strong's-style numbers attached to observed word tokens are preserved as source metadata evidence
only. Pronoun casing is inventoried as broad evidence only and does not decide whether a pronoun
refers to God, Christ, the Spirit, or another referent.

## Downstream Rule

Any future output-changing use of this inventory requires:

- owner review;
- exact scoped target;
- reviewed gold or equivalent governed evidence;
- decision-register update;
- executable tests;
- non-target identity proof;
- later implementation authorization.

## No Output Change

T353 does not modify raw data, canonical data, generated chunks, evaluators, route behavior, graph
edges, embeddings, retrieval indexes, or reviewed gold.
