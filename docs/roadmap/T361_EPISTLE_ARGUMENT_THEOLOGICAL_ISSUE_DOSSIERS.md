# T361 Epistle Argument Theological Issue Dossiers

## Purpose

T361 creates a research-only issue queue for epistle argument boundaries:

```text
.ai/control/epistle_argument_theological_issue_dossier_queue.yaml
```

The goal is to make future epistle review safer before any chunking algorithm work. Epistle
boundaries can accidentally encode theological positions about election, covenant continuity,
law/gospel, assurance, faith and works, sacramental language, Israel/church, and perseverance.
This queue records those risks so later reviewers can preserve orthodox options instead of
letting a boundary label become doctrine.

## Research Cases

The initial queue records:

- `Eph.1.3-Eph.1.14`: blessing, election, adoption, redemption, and sealing.
- `Rom.9-Rom.11`: Israel, election, mercy, hardening, and grafting.
- `Heb.7-Heb.10`: priesthood, covenant, sacrifice, exhortation, and warnings.
- `1Cor.8-1Cor.10`: conscience, idol food, liberty, example, and table language.
- `Gal.3-Gal.4`: law, promise, seed, sonship, and Hagar/Sarah argument.
- `Rom.7-Rom.8`: flesh, Spirit, assurance, adoption, and life in Christ.
- `Jas.2`: faith, works, justification, mercy, Abraham, and Rahab.
- `1Pet.3.18-1Pet.3.22`: suffering, spirits, Noah, baptism, and salvation language.
- `1John.1-1John.2`: fellowship, confession, advocacy, assurance, and obedience tests.
- `Jude.5-Jude.15`: examples, noncanonical references, and judgment.

The first four already have T352 packets. T361 does not edit those packets, does not promote them,
and does not create new reviewed gold.

## Preserved Options

The queue preserves orthodox options where they remain within Nicene/Chalcedonian Christianity,
including Reformed/Augustinian, Arminian/Wesleyan, corporate and individual election readings,
covenant continuity and discontinuity, classic law/gospel and New Perspective-sensitive readings,
perseverance and apostasy-warning readings, high sacramental and memorial/conscience readings,
faith/works harmony, justification distinctions, and union-with-Christ readings.

It does not select a confessional system, soteriology system, covenant system, sacramental
position, church-polity implication, or retrieval doctrine label.

## Non-Authorization

T361 does not authorize:

- epistle implementation
- route behavior changes
- evaluator changes
- reviewed-gold promotion
- chunk boundaries
- output changes
- graph edges
- retrieval truth
- embedding or vector work
- source metadata authority
- boundary import
- T345

Future output-changing use of any dossier still requires exact passage scope, owner review,
reviewed gold or equivalent governed evidence, non-target identity proof, validators/tests, and a
later implementation-authorizing decision.

## Validation

T361 adds:

- `scripts/validate_epistle_argument_theological_issue_dossier_queue.py`
- `tests/test_epistle_argument_theological_issue_dossier_queue.py`

The validator fails closed if the queue authorizes doctrine or output changes, loses required
orthodox options, drops the four T352 packet dependencies, treats pending packets as approved, or
omits non-authorization guards.
