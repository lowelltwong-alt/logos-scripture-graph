# T493 Patristics Boundary Intake Plan

T493 is a planning-only handoff from the canonical Scripture repository to future `logos-boundary-literature`. It creates no source selection, downloads, imports, boundary records, reception claims, doctrine claims, graph edges, retrieval/vector indexes, or theology authority.

The plan classifies Apostolic Fathers, ante-Nicene writers, Nicene/post-Nicene writers, councils, creeds, and disputed or fragmentary material as boundary source families. Classification is not acquisition readiness. Every future source needs edition, attribution, stable citation, language, translation, license, provenance, checksum, tradition scope, claim scope, confidence, and review status.

Any future intake must occur in `logos-boundary-literature` after governance registration is confirmed, the owner selects one source family and edition, license/provenance and attribution review pass, contamination tests exist, and default Scripture retrieval excludes the material.

Patristic material may document reception, comparison, controversy, or historical claims only within explicit scope. It must never become canonical Scripture text, default Scripture meaning, reviewed-gold evidence, evaluator input, preferred reading, graph truth, or doctrinal authority.

Unresolved questions remain questions: the first source family, an acceptable edition/translation license, and the attribution taxonomy for disputed works all require owner review.
