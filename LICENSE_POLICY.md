# License Policy

## Rule

No source text, lexical dataset, morphology dataset, cross-reference dataset, commentary, or translation may be imported without license metadata.

## Required fields

- source id
- title
- publisher/source
- license
- source URL or acquisition record
- raw archive path
- checksum
- permission constraints
- attribution requirements
- modification/trademark constraints

## WEB Classic

WEB Classic is planned as the first English full-text source. Record it as public domain with its trademark/modification notice.

## Copyrighted translations

Do not store full copyrighted translations unless a license explicitly permits the intended use. Store metadata/pointers only.
